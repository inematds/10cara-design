1

🗿 Claymation Character

A primeira das três variações extras mostra que o sistema também estica para estilos mais bizarros. A massinha grotesca leva o lock de identidade ao limite: features exageradas, mas ainda "a pessoa".

Por que funciona aqui

A linguagem de estilo (argila feita à mão, membros de macarrão) é forte o bastante para dominar a estética sem apagar a identidade da Ref 1.

Reaproveite o prompt de claymation do módulo 1.2 e só troque pose e props da cena miniatura.

2

🃏 Fake Cartoon ID Card

A segunda variação prova que layout rígido + execução caótica convivem. Uma carteirinha falsa, toda rabiscada, com dados bobos — e ainda assim reconhecível.

📊 O truque

O documento dá a estrutura (retrato + campos + carimbos), e o estilo doodle dá o humor. O "NÃO deve parecer documento real" no prompt é o que impede o resultado de ficar sério demais.

3

🖌️ Grotesque Fashion Sketch

A terceira variação estica a linguagem de sketch de moda ao máximo — anatomia exagerada, anotações sarcásticas, página de sketchbook estranho. Funciona porque o lock de identidade é forte o bastante para aguentar o exagero.

💡 Dica prática

Quando um estilo exagera muito a anatomia, reforce as âncoras de identidade no prompt (penteado, tom de pele, formato dos olhos) — assim o exagero recai sobre a roupa e a pose, não sobre o rosto.

4

🎯 Separação proposital

O motivo de tudo isso se manter estável: identidade e styling são separados de propósito. O rosto vem de uma referência e a moda de outra — o que mantém o resultado reconhecível sem travar numa pose única.

✓ Com separação

  • ✓Reconhecível em qualquer estilo
  • ✓Pose livre, mundo livre

✗ Sem separação

  • ✗Personagem muda a cada geração
  • ✗Resultado aleatório e imprevisível

🌐 Cada mundo, um gênero forte

A variedade vem de gêneros visuais bem definidos. Óleo, doodle, render de game, pôster de anime, promo open-world, editorial sentai, massinha, ID falsa, sketch grotesco e toy CGI — cada um produz uma saída radicalmente diferente da mesma pessoa.

A

Polidos & cinematográficos

Óleo surreal, pôster GTA, editorial sentai, toy CGI — alta produção e luz dramática.

B

Absurdos & meme

Doodle feio, ID falsa, massinha grotesca, sketch de moda — humor e imperfeição de propósito.

C

Colecionáveis & game

Card de Fortnite, pôster Pokémon — layout de interface e personagem de jogo.

6

⚙️ Workflow de reprodução

Do conceito à prática. Para reproduzir estes estilos — no Nano Banana 2 ou num servidor local como o inemaimg — siga quatro passos e escolha o modelo certo para o caso.

🧩 Modelo certo para cada caso

  • Duas referências (identidade + figurino): use um modelo edit-capaz que aceita imagens de entrada (ex.: Qwen-Edit).
  • Estilo único / sem referência: um modelo text-to-image puro basta (ex.: ERNIE) — foi assim que as imagens deste guia foram feitas.
  • Iteração rápida: baixe a resolução e os steps; só finalize em alta no take aprovado.
# exemplo: gerar um estilo único via inemaimg (text-to-image)
curl -s http://localhost:8000/generate \
  -H "Content-Type: application/json" \
  -d '{"model":"ernie","prompt":"3D designer-toy portrait ...","width":768,"height":1024}'

🔑 O passo a passo

  1. Travar o rosto — defina a identidade (Ref 1 ou descrição fixa do personagem).
  2. Trocar o gênero — escolha um dos 10 mundos do módulo 1.2.
  3. Pose nova — descreva uma pose específica que case com o cenário.
  4. Gerar e iterar — gere barato, ajuste o prompt, finalize em alta.
