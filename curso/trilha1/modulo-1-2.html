💡 Como usar

Anexe duas imagens no Nano Banana 2: Referência 1 (a pessoa) e Referência 2 (inspiração de figurino). Cole o prompt, gere, e repita trocando só o estilo. As imagens ao lado de cada prompt foram geradas localmente com inemaimg como exemplo do mundo visual resultante.

1

🖼️ Surreal Oil Painting

Surreal mid-century editorial oil painting of the person from Reference 1, using Reference 1 as the main character identity, face structure, skin tone, hairstyle, facial proportions, and overall recognizable appearance. Use Reference 2 only as inspiration for the outfit, clothing silhouette, fabric type, accessories, color palette, styling details, and fashion mood. Do not copy the pose from Reference 1 or Reference 2. Create a new relaxed seated pose: the character is sitting confidently in a vintage lounge chair, one leg crossed, one arm resting on the chair, looking slightly away from the viewer with a calm deadpan expression. Place the subject in a stylish surreal lounge interior with cinematic lowbrow atmosphere, elegant café culture energy, strange background characters softly blurred in the distance, palm shadows, distorted decorative architecture, vintage lamps, wine glasses, newspapers, oversized jewelry, and subtle bizarre animal elements integrated into the scene. Painterly brush textures, expressive oil-painted strokes, rich muted color palette, fashionable vintage clothing, sophisticated absurdity, surreal editorial illustration, cinematic composition, contemporary art gallery mood, vertical 4:5 composition. Maintain the recognizable character from Reference 1 while changing the outfit according to Reference 2.

2

✏️ Funny Doodle

Turn the person from Reference 1 into a funny ugly doodle drawing, using Reference 1 as the character identity, face reference, hairstyle, facial features, skin tone, and general appearance. Use Reference 2 only for the outfit, clothing style, accessories, colors, and fashion details. Do not copy the pose from either reference. Make a new awkward pose: the character is standing slightly hunched, arms half-raised in a confused gesture, with exaggerated facial features and a silly uncomfortable expression. Make it look like a quick sketch using cheap marker and crayon: messy, rough, childish style, bad perspective, awkward proportions, slightly exaggerated facial features, uneven outlines, visible scribbly strokes, simple cartoon coloring, lazy internet meme energy. Add a simple cartoon background with random street details, funny small objects, crooked signs, clouds, goofy doodles, badly drawn buildings, and chaotic humorous details. The drawing should look casual, low-quality, hand-made, intentionally stupid-looking, and meme-like. Do NOT make it realistic or polished.

3

🎮 Fortnite Shop

Create a hyper-realistic Fortnite Item Shop character card using Reference 1 as the exact face and identity reference. Preserve the recognizable facial structure, hairstyle, skin tone, proportions, and overall character likeness from Reference 1. Use Reference 2 only for the outfit design, clothing colors, styling details, accessories, and fashion direction. Do not copy the pose from the references. Create a new full-body Fortnite-style character pose: the character stands slightly turned to the side, one hand near the belt or pocket, the other relaxed, with confident game-character posture. Keep the same Fortnite shop layout with a blue gradient background, rarity banner, V-Bucks pricing, cosmetic item icons on the left, and a full-body character render on the right. Transform the person into a stylish urban Fortnite skin with polished stylized realism, clean proportions, detailed clothing inspired by Reference 2, high-quality game render lighting, realistic fabric textures, sharp character presentation, and official item-shop card composition. Add fictional cosmetic icons matching the outfit style: head icon, accessory, emote, back bling, and weapon charm. Make the text and interface look game-like and readable without copying any real brand text.

4

⚡ Pokémon Poster

Create an ultra-detailed cinematic Pokémon-style poster featuring the person from Reference 1 as a confident Pokémon champion. Use Reference 1 as the main face and identity reference, preserving facial features, skin tone, hairstyle, facial structure, eye shape, and overall recognizable appearance. Use Reference 2 only for the outfit inspiration: clothing silhouette, colors, materials, accessories, and fashion mood. Do not copy the pose from Reference 1 or Reference 2. Create a new heroic pose: the champion stands in three-quarter view, one hand holding a Poké Ball near the chest, the other hand resting near the waist, looking confidently toward the viewer. Style combines semi-realistic anime painting, cinematic game-poster aesthetics, modern Pokémon concept art, painterly brush strokes, soft polygonal shading, highly detailed character illustration, premium trading-card artwork, and Japanese gaming magazine cover design. Add several original creature companions around the character: one small electric creature near the shoulder, one dragon-like creature behind the character, one small water creature near the foreground, and one ghostly creature in the background. Vertical poster layout, champion centered in a heroic pose, clean cream-colored background, minimalist editorial styling, dynamic energy effects, detailed typography-like graphic elements, barcode-style decorative marks, and premium collectible poster atmosphere.

5

🌴 GTA 6 Poster

Create a highly detailed 8K portrait poster inspired by the visual style of a modern open-world crime game promotional artwork aesthetic. Use Reference 1 as the exact character identity, face, hairstyle, skin tone, facial structure, and body proportions reference. Use Reference 2 only for the outfit, clothing style, colors, accessories, fabrics, and overall fashion direction. Do not copy the pose from either reference. Create a new cinematic pose: the character is leaning against the hood of a luxury car at night, one hand resting behind them, the other relaxed near the thigh, looking off-camera with confident calm attitude. The poster should feature a cinematic urban atmosphere with bold composition, vibrant neon lighting, layered graphic elements, palm tree shadows, wet asphalt reflections, luxury vehicle silhouettes, nightlife signs, dramatic sunset-to-night color grading, glossy highlights, stylized textures, and modern street-luxury fashion energy. Add fictional city-poster typography, abstract shapes, small decorative texts, game UI-style elements, barcode marks, warning-label style details, and cinematic poster graphics. The design should feel like a high-budget video game cover artwork while keeping the person from Reference 1 recognizable and dressing them according to Reference 2.

6

🦸🏾 Black Superhero / Power Ranger

Create a high-fashion cinematic editorial portrait of the person from Reference 1 as a black superhero inspired by classic team-sentai / ranger aesthetics. Use Reference 1 as the character identity, face, hairstyle, skin tone, facial proportions, and recognizable appearance. Use Reference 2 only for fashion inspiration, outfit details, texture references, accessories, and styling mood, but transform the final costume into a sleek black superhero suit instead of any blue suit. Do not copy the pose from the references. Create a new powerful pose: the character is sitting on a concrete ledge, leaning slightly forward, elbows resting on knees, looking directly at the viewer with a calm intense expression. The subject wears a slim-fit metallic black superhero spandex suit with subtle white geometric diamond patterns, armored paneling, glossy black materials, tactical seams, and premium high-fashion detailing. Beside the subject on the ground is a matching black superhero helmet with a reflective visor. Behind the subject towers a massive hyper-realistic black mechanical animal zord made of weathered dark metal, glowing red eyes, heavy armor plates, and cinematic scale. Shot from a low angle with a professional DSLR wide-angle lens. Dramatic golden-hour backlighting, glowing dust particles, smoke, industrial rooftop environment, futuristic minimalist HUD graphics, white technical interface text, cinematic depth, high-detail realism, editorial superhero poster mood.

7

🟤 Claymation Effect

Transform the person from Reference 1 into an absurd claymation character while keeping the exact composition logic of a portrait scene, but use a new pose. Reference 1 is the identity reference: preserve the recognizable face, hairstyle, skin tone, facial proportions, and character essence. Reference 2 is only for the outfit, clothing silhouette, colors, accessories, and styling details. Do not copy the poses from either reference. Create a new claymation pose: the character is sitting at a small table, one hand raised awkwardly, the other resting on the table, with a startled cartoon expression. Grotesque claymation caricature style, noodle-like limbs, slightly oversized hands, bulging misaligned eyes, uneven teeth, visible pink gums, wonky facial anatomy, exaggerated but recognizable features, rough handmade clay texture, fingerprints, scratches, dents, soft studio lighting, macro depth of field, stop-motion aesthetic, handmade miniature environment. Keep the outfit inspired by Reference 2 but recreated as clay fabric with visible sculpted folds and rough texture. The background should look like a miniature set with simple props, uneven surfaces, handmade furniture, and intentionally imperfect craft details. 8k, tactile clay texture, absurd humorous mood.

8

🪪 Cartoon Doodle ID

Create a fake cartoon-style ID card featuring the person from Reference 1 as a messy crayon and marker doodle portrait. Use Reference 1 as the face, hairstyle, skin tone, facial structure, and identity reference. Use Reference 2 only for outfit style, colors, accessories, and fashion details. Do not copy the original pose. Create a new exaggerated ID portrait pose: front-facing head-and-shoulders portrait with a huge goofy smile, raised eyebrows, slightly uneven eyes, and funny cartoon expression. Make the entire ID card look hand-drawn with crooked text, uneven coloring, scribbly textures, thick outlines, childish handwriting, random stickers, doodles, stars, hearts, palm trees, fake stamps, fake numbers, and chaotic meme energy. Add intentionally fake personal details, silly labels, and playful handwritten notes around the portrait. The card should look like a low-quality sketchbook drawing made with cheap crayons and markers. Use the outfit influence from Reference 2 in the cartoon portrait, but simplify it into doodle form. Do NOT make it realistic, professional, official, or believable as a real document.

9

👠 Fashion Caricature

Turn the person from Reference 1 into a grotesque humorous fashion caricature sketch. Use Reference 1 as the main identity reference, preserving recognizable facial features, hairstyle, skin tone, facial structure, and general character likeness. Use Reference 2 only for the outfit, clothing proportions, accessories, fashion mood, fabrics, and styling details. Do not copy the pose from either reference. Create a new fashion pose: the character stands in a dramatic contrapposto stance, one shoulder raised, one hand tucked into clothing, the other hanging awkwardly, with an overly serious fashion expression. Strongly exaggerated anatomy, elongated proportions, expressive crooked hands, dramatic face, awkward elegant posture, satirical fashion energy, messy ink lines, rough watercolor shading, sketchbook style, vintage magazine illustration on beige aged paper. Add handwritten English notes, arrows, funny observations, absurd personality analysis, fake fashion ratings, tiny doodles, fabric callouts, object sketches, and sarcastic style annotations around the character. Keep the outfit inspired by Reference 2 but exaggerate it into a strange high-fashion silhouette. The final image should look like an editorial fashion analysis page from a weird sketchbook.

10

🧸 3D Toy Portrait

Create a stylized 3D designer-toy portrait of the person from Reference 1. Use Reference 1 as the exact identity reference for the face, hairstyle, skin tone, facial proportions, facial structure, and recognizable character features. Use Reference 2 only for outfit inspiration: clothing style, accessories, colors, materials, patches, jewelry, shoes, and fashion mood. Do not copy the pose from Reference 1 or Reference 2. Create a new centered close-up pose: the character faces the camera directly with a calm detached expression, shoulders slightly angled, head subtly tilted, symmetrical designer-toy portrait composition. High-end CGI aesthetic blending Pixar-level smoothness with street-fashion vinyl toy design, soft global illumination, subtle subsurface scattering, ultra-clean rendering, glossy accessories, smooth stylized skin, detailed clothing recreated from Reference 2 as premium toy-like materials. Add playful sticker patches, fashion-tech accessories, miniature badges, small logo-style decorations, removable toy-like elements, cyber-minimalist details, and collectible figure branding. Background: clean matte studio gradient, soft shadows, premium product-photography lighting. The final image should feel like a luxury collectible designer toy portrait with futuristic Gen-Z fashion editorial energy, cute rebellion, cyber-minimalism, and high-end 3D character design.
